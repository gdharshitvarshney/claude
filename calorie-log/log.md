# Daily Calorie Log

This file is the running record of everything logged via the `/calories_log`
command. Newest day is at the top. Each entry is a food item with an estimated
calorie count; the **Daily total** under each day sums that day's entries.

> Estimates are approximate (typically within ±20% for whole meals). See
> [`README.md`](README.md) for the daily target and how it was calculated.
